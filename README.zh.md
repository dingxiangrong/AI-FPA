# AI-FPA 归因仓库
> AI-Fault & Performance Attribution｜AI 故障与性能归因系统

## 仓库定位
**全体系免疫系统，对应六部体系之【验部】**
负责工程排障、逻辑审证、公理自洽检验，承接整套六部五道体系落地后的校验、归因、纠错与回炉迭代闭环。
> 理论溯源：源自 **A31：系统之道第一篇——三道十二律 1.3 归因四律**，为本仓库顶层理论约束。

## 核心职责
1. **工程排障**：捕获LLM隐性工程陷阱（Prompt内循环陷阱、串行解码放大效应等），定位延迟、异常输出、性能退化根因。
2. **逻辑审证**：校验工程实现是否对齐理论范式，识别反范式实现、隐性控制流风险。
3. **公理自洽检验**：对照大模型工程公理，核查落地成果与底层公理是否冲突。
4. **归因回流**：遵循归因四律，将故障、性能问题的归因结论反向回输至根仓库，驱动理论迭代优化。

## 关键产出物
- FPA-L1 工程级故障与性能案例归档文档
- LLM工程公理库、陷阱定义、标准化检测范式
- 校验报告、问题归因记录、优化改进建议

## 体系链路
iTuLink工程落地仓库 → AI-FPA归因仓库（验核纠错，执行归因四律） → 回流【根仓库】完成全域闭环

## 关联体系
